# aiscan 依赖清单（Python 3.12+）
# ==============================================================================
# 本工具链刻意保持极简依赖：所有检测器一律用正则实现，
# 不引入解析库、不引入浏览器驱动（见 README「为什么没有用 playwright」一节）。

#     pip install -r requirements.txt
# 或者直接跑包内的一键脚本（它会自动建环境并安装本清单）：
#     install.ps1        （Windows）
